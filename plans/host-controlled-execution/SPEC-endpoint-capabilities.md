# endpoint-capabilities

OpenAI constructor exposes `endpoint: auto|responses|chat_completions` and `fallback: compatible|error`. Default auto preserves model selection; compatible default only falls back before stream establishment when no semantic feature would be lost. Required responses never falls back. Explicit chat rejects required Responses tools, reasoning+tools conflicts, Responses replay, reasoning mode/context/summary and Responses-only cache semantics. Fallback cannot silently set reasoning to none. Preserve explicit reasoning disabled/none on Responses and mode/context with omitted effort. Continue validating replay owner/model before transport.

Expose shared `ModelCapabilities` and validation independent of data source. Optional host facts: context/output token limits, reasoning efforts/modes, tools support, closed-turn history eviction. Configured known incompatibility fails before transport; unknown fields are allowed by default or rejected with explicit strict policy. Context counts are advisory estimates unless supplied by a trusted estimator; provider rejection remains authoritative. No built-in registry or remote lookup. Capabilities supplied on OpenAI/Anthropic configs and optional provider contract support harness preflight for other adapters.
